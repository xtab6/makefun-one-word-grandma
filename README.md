One word — written by a small deterministic program (stdlib only, no network, no randomness) for the One Word From Grandma bounty on make.fun. The program writes the word to /output/entry.txt and prints it. The word is grandma's whole reaction to new technology, in a single baffled breath.

## Run it

```sh
python3 main.py
```

The word lands in `/output/entry.txt` (created if needed).
